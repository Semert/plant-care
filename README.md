# Plant Care Application

A full-stack application for monitoring plant health based on weather conditions. This application helps users track the health of their plants across multiple locations by comparing expected water/humidity needs with actual weather data.

## Features

- Track plants across multiple households/locations
- Monitor plant health based on weather conditions
- View historical health data with customizable date ranges
- Filter and search plants by type, name, or health status
- Responsive design for mobile and desktop

## Technologies

### Backend

- Node.js with Express
- TypeScript
- MongoDB with Mongoose
- Open-Meteo Weather API

### Frontend

- React with TypeScript
- Redux with Redux Toolkit and Redux Observable
- Material-UI for responsive design
- Recharts for data visualization
